# AtmosHero · ODS 13: Acción por el clima

Sitio web estudiantil con información e ideas cotidianas para cuidar el clima.
Es estático (HTML, CSS y JavaScript sin dependencias) y funciona en GitHub Pages.

**Sitio publicado:** https://u202420740-lab.github.io/AtmosHero-ODS-13/

## Características
- Menú accesible con versión móvil (`js/menu.js`).
- Orientador de acciones ambientales (solo CSS).
- Gráfico "Emisiones por categoría" con **Modo Inclusivo**: patrones, iconos y texto además del color (`js/grafico-emisiones.js`). Los datos son de demostración.
- Lector de voz flotante con control de velocidad (`js/lector-voz.js`).
- Enlace de salto al contenido, formulario con etiquetas y navegación por teclado.

## Estructura
```
index.html  recursos.html  confirmacion.html
css/  js/  iconos/  imagenes/
```
`index.html` debe estar en la **raíz** del repositorio para que GitHub Pages lo use como portada.
